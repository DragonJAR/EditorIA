# Brand packs

Un brand pack concentra toda la identidad de una marca en un solo JSON.
El skill nunca hardcodea marca: la lee del pack. Sin pack, modo libre.

- Pack de ejemplo: `brand/dragonjar.json`
- Spec completo: `references/brand-packs.md`

Uso: `scripts/ffmpeg_tools/caption.py --brand brand/dragonjar.json ...`
